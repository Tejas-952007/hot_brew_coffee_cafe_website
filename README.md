## ✨ Overview
Brew Haven Café is a full-stack, production-ready web application featuring a stunning, Dribbble-inspired user interface. It combines a highly aesthetic frontend with a robust Node.js backend to handle real-world café operations, from dynamic cart management to secure order processing and user authentication.

## 🚀 Key Features
- **Ultra-Modern UI:** Asymmetrical "Bento Grid" layout, glassmorphism elements, and animated aurora backgrounds.
- **E-Commerce Checkout:** Real-time cart updates, dynamic subtotal calculations, and a secure checkout modal.
- **User Authentication:** Complete user registration, secure login, and session persistence.
- **Database Integration:** MySQL-backed systems for managing dynamic menus, table reservations, and order histories.
- **Smooth Micro-Interactions:** Custom hover states, scrolling parallax effects, and toast notifications for premium UX.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (No frameworks)
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **Security:** bcrypt (password hashing), express-session

## ⚙️ Quick Start

### 1. Database Setup
Create a new MySQL database and ensure your local MySQL server is running.

### 2. Environment Configuration
Clone the `.env.example` file to create your local `.env` configuration:
```bash
cp .env.example .env
```
*Update `.env` with your specific MySQL credentials.*

### 3. Install & Run
Install the backend dependencies and start the server. The application will automatically create all necessary database tables and seed the initial menu upon the first launch.
```bash
npm install
node server.js
```
Visit `http://localhost:3000` to experience the café!
